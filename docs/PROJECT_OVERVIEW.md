# Project: LensLease (Camera Gear Tracker & P2P Rental)

## Vision
A web application to track personal camera equipment inventory. 
- Phase 1: Personal storage/inventory tracker.
- Phase 2: Friend-to-friend borrowing system.
- Phase 3: P2P rental marketplace with payments.

## Tech Stack (The "Powerhouse" Stack)
- **Framework:** Next.js 14+ (App Router)
- **Language:** TypeScript
- **Database/Auth:** Supabase (PostgreSQL)
- **Styling:** Tailwind CSS + shadcn/ui
- **ORM:** Prisma or Drizzle (TBD)
- **State Management:** React Server Components + Zod for validation

## Core Principles
- **Mobile First:** Must be usable in a storage unit or on a film set.
- **Image Centric:** High-quality visuals of gear are a priority.
- **Security:** Use Row Level Security (RLS) from Day 1.
